```
$ pasejo store help create-remote
Create a store on a server and register it

Usage: pasejo store create-remote [OPTIONS] <LABEL>

Arguments:
  <LABEL>  The store's label, encrypted on the server

Options:
  -n, --name <NAME>  The local name of the store. Defaults to the label
  -d, --default      Whether the new store should be the default store
  -o, --org <ORG>    Name or identifier of the organization. Defaults to the only registered organization
  -v, --verbose...   Increase logging verbosity
  -q, --quiet...     Decrease logging verbosity
  -h, --help         Print help

```
