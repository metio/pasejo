```
$ pasejo store help add-remote
Register a store that exists on a server

Usage: pasejo store add-remote [OPTIONS] --name <NAME> <STORE>

Arguments:
  <STORE>  The store's identifier, as `pasejo org stores` lists it

Options:
  -n, --name <NAME>  The local name of the store
  -d, --default      Whether the store should be the default store
  -o, --org <ORG>    Name or identifier of the organization. Defaults to the only registered organization
  -v, --verbose...   Increase logging verbosity
  -q, --quiet...     Decrease logging verbosity
  -h, --help         Print help

```
