```
$ pasejo org help approve
Approve a pending device

Usage: pasejo org approve [OPTIONS] <DEVICE>

Arguments:
  <DEVICE>  The device's identifier

Options:
      --fingerprint <FINGERPRINT>  The device's fingerprint, compared with the one its owner sees
  -o, --org <ORG>                  Name or identifier of the organization. Defaults to the only registered organization
  -v, --verbose...                 Increase logging verbosity
  -q, --quiet...                   Decrease logging verbosity
  -h, --help                       Print help
```
