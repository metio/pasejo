$ pasejo server help logout
Sign out of a server

Usage: pasejo server logout [OPTIONS] [URL]

Arguments:
  [URL]  The server's base URL. Defaults to the only registered server

Options:
      --forget      Also remove the device's keys and registration
  -v, --verbose...  Increase logging verbosity
  -q, --quiet...    Decrease logging verbosity
  -h, --help        Print help
