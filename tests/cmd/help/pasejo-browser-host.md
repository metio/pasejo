```
$ pasejo browser help host
Run a native-messaging host that browser extensions connect to

Usage: pasejo browser host [OPTIONS]

Options:
      --only-store <ONLY_STORE>        Restrict the host to these stores. Stores outside the list are invisible to the connecting extension. Repeatable
      --default-store <DEFAULT_STORE>  Use this store when a request omits the store field. Defaults to the usual default-store / first-store fallback chain
      --username-keys <USERNAME_KEYS>  [default: login email username]
      --uri-keys <URI_KEYS>            [default: uri url link site]
  -v, --verbose...                     Increase logging verbosity
  -q, --quiet...                       Decrease logging verbosity
  -h, --help                           Print help

```
