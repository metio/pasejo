```
$ pasejo org help recover
Decrypt every store with the organization's recovery identity

Usage: pasejo org recover [OPTIONS] --identity <IDENTITY> --output <OUTPUT>

Options:
      --identity <IDENTITY>  The organization's recovery identity
      --output <OUTPUT>      The directory receiving one file store per remote store, encrypted to the recovery recipient
  -o, --org <ORG>            Name or identifier of the organization. Defaults to the only registered organization
  -v, --verbose...           Increase logging verbosity
  -q, --quiet...             Decrease logging verbosity
  -h, --help                 Print help
```
